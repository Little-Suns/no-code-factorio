# Правила для агентов

Хакатон-проект: фабрика AI-агентов в стиле Factorio (идейно n8n). Времени мало — минимализм обязателен.

## Перед любой задачей

1. Прочитай `docs/01-architecture.md` (типы и контракты) и профильный док своей задачи (см. `docs/08-roadmap.md`).
2. Вопросы «как это устроено в n8n» — только в `docs/09-n8n-reference.md`; внешние репозитории (включая n8n-io/n8n) не ресерчить.
3. Не меняй канонические типы из `web/src/core/types.ts` без крайней необходимости — на них завязаны все треки. Если изменил — обнови docs/01 и упомяни в отчёте.

## Стек (зафиксирован, не менять)

- `web/`: Vite + React 18 + TypeScript strict + PixiJS v8 + pixi-viewport + Zustand
- `server/`: Python 3.12 + FastAPI + uvicorn + httpx — один файл `main.py`
- Пакетный менеджер: pnpm для web, pip/requirements.txt для server
- Разрешённые зависимости — только перечисленные выше. Новые не добавлять: пара строк кода дешевле зависимости.

## Архитектурные инварианты

- `web/src/core/` — чистый TS: **никаких импортов** из pixi.js, react, zustand. Движок проверяется без браузера (FakeTransport).
- Тайл = **64px**. Направления `Dir`: 0=N(вверх), 1=E, 2=S, 3=W, по часовой.
- Рендер узнаёт о мире через Zustand-подписку и события движка; UI — обычные React-хуки.
- Спрайты подключаются только через `web/public/assets/manifest.json`; нет файла — программный плейсхолдер. Код под конкретный PNG не пишем.
- LLM-вызовы — только через сервер `/llm`: реальный OpenAI-compatible API (OpenRouter по умолчанию, конфиг через env). Мок — только fallback при отсутствии ключа; фронт этого не различает.
- MVP-ядро: belt, miner (текст/URL/вебхук), assembler, splitter, mixer, silo, telegram. Усиление (только после ядра, в порядке приоритета): электричество (аккумулятор, заряд = токены LLM), MCP-модули (веб-поиск), furnace/chest/lab, энергостолбы-ЛЭП + чертежи.
- Анти-скоуп (не реализовывать): обработка изображений моделями, электросеть-провода, враги, исследования, подземные ленты, undo/redo, мобильная версия, авторизация, мультиплеер.

## Definition of Done

- `pnpm -r typecheck` без ошибок
- Работает в браузере (проверь руками сценарий из acceptance criteria задачи)
- Для нетривиальной логики в `core/` — маленький assert-файл `web/src/core/__checks__/<тема>.ts`, запускаемый `pnpm --filter web check` (без фреймворков)
- Отчёт: отметь чекбокс задачи в `docs/08-roadmap.md`, 1–3 строки заметок

## Стиль

- Идентификаторы английские, комментарии можно по-русски
- Функции и модули; классы только там, где есть состояние с жизненным циклом (Engine)
- Каждая задача — минимальный диф. Не рефактори чужие треки.
